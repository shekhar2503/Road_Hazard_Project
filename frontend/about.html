SYSTEM OVERVIEW ABOUT THE PROJECT

Safer roads through
computer vision.

The Road Hazard Detection System leverages YOLO-based object detection to automatically identify and map road hazards from images, enabling faster civic response and safer routing.

!
THE PROBLEM

Manual reporting is slow.

Road conditions deteriorate rapidly, but municipal authorities often rely on slow, manual reporting processes or periodic surveys. This lag in reporting leaves hazards like potholes and open construction barriers unaddressed, leading to vehicle damage and safety risks.

OUR SOLUTION

HOW IT WORKS

01. CAPTURE

Public users upload road images to the system.

arrow_downward
02. DETECTION

A custom YOLO model analyzes the image to classify hazards and assign confidence scores.

arrow_downward
03. STORAGE

Detected hazards, along with geolocation data, are saved to a PostgreSQL/PostGIS database.

arrow_downward
04. ACTION

Hazards are visualized on a map, reported to municipal authorities, and can be used for safer route recommendations.

TECHNOLOGY STACK

Built for performance.

COMPUTER VISION

YOLO (You Only Look Once) custom-trained model for high-speed, high-accuracy object detection.

BACKEND & DATABASE

PostgreSQL with PostGIS extensions for robust spatial data storage and geographic querying.

FRONTEND

Vanilla HTML, CSS, and JavaScript. Zero bloat, maximum performance.
